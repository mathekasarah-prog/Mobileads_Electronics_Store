## About

Mobileads is an e-commerce storefront for electronics and gadgets, built with plain HTML, CSS, and JavaScript. It includes product browsing, a clickable product detail modal, and a full site footer with shop links, customer care info, and company details.

## Features

* 🛍️ Product listings (All Products, New Arrivals, Best Sellers, Deals)
* 🔍 Product detail modal — click a product to view full details without leaving the page
* 📱 Responsive footer with shop, customer care, and company navigation
* 🎨 Clean, lightweight UI with no framework overhead

## Tech Stack

* HTML5
* CSS3 (Flexbox / Grid layouts)
* Vanilla JavaScript

## Getting Started

### Prerequisites

* A modern web browser
* (Optional) [VS Code](https://code.visualstudio.com/) with the Live Server extension for local development

### Installation

```bash
git clone https://github.com/mathekasarah-prog/mobileads.git
cd mobileads
```

### Running Locally

Simply open `index.html` in your browser, or if using VS Code:

1. Install the **Live Server** extension
2. Right-click `index.html` → **Open with Live Server**

## Usage

Click on any product card to open its detail modal, showing the product image, name, price, and description. Use the "Add to Cart" button to add items (or wire this up to your cart logic).

Navigate the footer to reach:
* **Shop** — All Products, New Arrivals, Best Sellers, Deals
* **Customer Care** — Contact Us, Shipping and Delivery, Returns and Refunds, Warranty
* **Company** — About Mobileads, Membership, Careers, Press, Affiliates

## Known Issues / Limitations

* Cart and checkout functionality not yet implemented
* No backend — product data is currently static/hardcoded
* Not yet tested across all mobile breakpoints
